# Security policy

Do not disclose employee, payroll, banking, tax, medical, injury or identity data
in public issues. Report suspected vulnerabilities privately to the repository
maintainers with the affected app/version, reproducible steps and impact.

Supported security fixes target the currently pinned Frappe/ERPNext/HRMS v16
stack. Keep production sites on reviewed release tags, apply least privilege,
encrypt backups, test restores and preserve statutory audit logs.

Assign `ZA Compliance User`, `ZA Compliance Reviewer` and `ZA Compliance Manager`
only to distinct accountable users where maker/checker separation is required.
Feature Readiness and a successful test run do not relax Company/User Permissions
or authorise external filing.
